# Views without a front end

The working base supports an authorised operator who records case facts, asks questions, prepares briefs and reviews the week's work. The CLI writes the records. Read-only HTML shows them and prints them.

A screen adds browser access for a wider team, a visual relationship graph, mobile capture, inline annotation, drag-and-drop evidence intake and guided forms. Offline field capture requires its own synchronisation design. The free base has no mobile application, public intake form, investigator login or shared evidence vault.

Enterprise DNA builds the agreed screens, access controls and connections around the same records when the business needs them. Those are separate implementation work. The local casework and review routines work without them.

Generated HTML is private output. It does not send, publish, file with a court or notify a case party.
